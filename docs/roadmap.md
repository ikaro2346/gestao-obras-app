# Roadmap

## Fase 1 - Protótipo Local

- Dashboard financeiro.
- Etapas da obra.
- Lançamentos de custos.
- Unidades da obra geminada.
- Ranking de maiores custos.
- Curva ABC de materiais.
- Relatórios e exportação.

## Fase 2 - Organização Para Desenvolvimento

- Repositório no GitHub.
- README e documentação básica.
- Fluxo de branches e Pull Requests.
- Lista de tarefas priorizadas.
- Padrão simples de contribuição.

## Fase 3 - App Compartilhado

- Login de usuários.
- Obras compartilhadas.
- Membros por obra.
- Permissões de dono, editor e visualizador.
- Banco de dados na nuvem.
- Histórico de alterações.

## Fase 4 - Recursos De Obra

- Upload de notas fiscais e fotos.
- Relatórios em PDF.
- Importação/exportação Excel.
- Controle de fornecedores.
- Controle de estoque/material comprado x aplicado.
- Cronograma físico-financeiro.
- Medição por etapa.

## Fase 5 - Produto Comercial

- Multiobras.
- Painel administrativo.
- Plano gratuito/pago.
- Backup automático.
- Notificações.
- Auditoria completa.
