# Como Contribuir

## Fluxo Recomendado

1. Atualize a branch principal.
2. Crie uma branch nova para sua melhoria.
3. Faça alterações pequenas e focadas.
4. Teste no navegador.
5. Abra um Pull Request.

## Padrão De Branch

```text
feature/nome-da-funcionalidade
fix/nome-do-ajuste
docs/nome-da-documentacao
```

## Antes De Enviar

- Verifique se o app abre no navegador.
- Teste em largura de celular e desktop.
- Confira se não há erro no console.
- Não misture várias ideias grandes na mesma branch.

## Convenção De Commit

Use mensagens simples:

```text
feat: adiciona fornecedores
fix: corrige cálculo da curva abc
docs: atualiza roadmap
```
